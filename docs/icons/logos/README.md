# Loga sieci używanych w aplikacji „Jak daleko?”

Te pliki to **znaki towarowe** poszczególnych firm i instytucji. Są tu wyłącznie po to, żeby w aplikacji oznaczyć konkretną sieć punktów (np. InPost, Żabka, Metro Warszawskie). To nie jest licencja na inne użycie znaku, na sugerowanie współpracy z marką ani na zmianę wyglądu logo.

Skąd pochodzą pliki:

- Wikimedia Commons – zwykle public domain jako proste logo tekstowe/geometryczne (**PD-textlogo**), przy czym sam znak nadal jest znakiem towarowym.
- Oficjalna strona lub press/asset firmy – bez osobnej licencji Commons; też znak towarowy.

Gdy dało się znaleźć oficjalne **SVG**, jest w katalogu razem z **PNG** (dłuższy bok 512 px, przezroczyste tło poza samym znakiem). Dla Biedronki i Stokrotki nie znaleziono oficjalnego SVG – jest tylko PNG.

Katalog nie obejmuje kategorii ogólnych z aplikacji (szkoła, apteka, przystanek, „dowolny automat” itd.) – to nie są pojedyncze marki. Pełna lista pominiętych sieci jest w raporcie przekazania.

Nie rysowano logo samodzielnie i nie poprawiano ich wyglądu.
